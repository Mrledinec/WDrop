# Обмен файлами Windows ↔ Android

Оба устройства подключаются к одной локальной сети. Приложение Windows запускает локальный HTTPS-сервер, а приложение Android подключается к нему. Доступ в интернет нужен для установки зависимостей и сборки.

[Перенос разработки на другой компьютер](docs/DEVELOPMENT.md)

## Запуск на Windows

Для обычного запуска установите `LocalTransfer-Setup-<версия>.exe` из папки `dist` или из GitHub Releases проекта. Установщик добавляет ярлыки на рабочий стол и в меню «Пуск».

### Запуск из исходников

Откройте PowerShell в корне проекта. Для первой настройки установите зависимости в локальное окружение.

~~~powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r desktop_win\requirements.txt
~~~

Запустите приложение.

~~~powershell
.\.venv\Scripts\python.exe -m desktop_win.main
~~~

Чтобы добавить ярлык «Обмен файлами» на рабочий стол, запустите `scripts/install_windows_shortcut.ps1`. Закрытие и сворачивание окна убирают его в системный трей. «Выход» в меню значка останавливает приложение.

Windows сохраняет полученные файлы в папку Downloads\Local Transfer. Папку можно изменить через «Настройки» → «Папка для полученных файлов». Приложение слушает TCP-порт 8000 по умолчанию. Выберите Wi-Fi или Ethernet в списке «Локальная сеть». Приложение публикует адрес для поиска и сопряжения только в выбранной сети. Для запуска сервера только на одном IP используйте параметр `--bind`.

## Сборка и подключение Android

В папке android_app выполните команды.

~~~powershell
flutter pub get
flutter build apk --debug --target-platform android-arm64
~~~

На компьютере с другой версией NDK можно указать установленную версию в android_app/android/local.properties ключом transfer.ndkVersion. По умолчанию сборка использует версию NDK из Flutter.

Установите APK из android_app/build/app/outputs/flutter-apk/app-debug.apk. Выберите локальную сеть на обоих устройствах. Для точки доступа телефона можно оставить «Автоматически» на Android. На ПК нажмите «Подключить телефон». На Android отсканируйте QR или нажмите «Искать в сети», выберите ПК и введите шесть цифр из окна Windows. Код действует две минуты. Затем подтвердите сопряжение на ПК.

Сопряжённые устройства сохраняют учётные данные локально. При смене IP приложение Android может найти новый адрес ПК через mDNS, сверить сертификат и восстановить подключение с сохранённым ключом. Если сеть не пропускает mDNS, адрес можно изменить в меню сопряжённого компьютера.

Чтобы получать файлы, включите на телефоне «Готов принимать» и разрешите уведомления. Полученные файлы появятся в Download/Local Transfer. Для отправки с телефона нажмите «Отправить файл на ПК» или выберите «Обмен файлами» в системном меню «Поделиться». В Windows можно также перетащить файлы прямо в окно приложения.

Ручное подтверждение действует 60 секунд. В настройках конкретного устройства можно включить автоприём. Лимит приёма на каждой стороне по умолчанию равен 2048 МиБ. Значение 0 отключает ограничение размера, свободное место проверяется при любой настройке.

Во время отправки и приёма отображается прогресс. В истории Windows нажмите правой кнопкой на запись, а на Android удерживайте её, чтобы открыть действия с файлом. Пункт «Очистить историю передач» в настройках удаляет только записи.

Спецификация сетевого API находится в shared/api_spec.json.

## Сборка Windows-установщика

Установите Inno Setup и PyInstaller в окружение сборки. Из корня проекта выполните команды.

~~~powershell
.\.venv\Scripts\python.exe -m pip install "pyinstaller>=6.17,<7"
.\scripts\build_windows.ps1 -InnoCompiler "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
~~~

## Обновления

На Windows и Android откройте «Настройки» → «Проверить обновление». Приложение покажет установленную версию и проверит последний стабильный выпуск [Mrledinec/WDrop](https://github.com/Mrledinec/WDrop/releases). Если доступна новая версия, кнопка «Установить» скачает и проверит установщик по SHA-256. На Windows приложение закроется после подтверждения запуска установщика. На Android установку нужно подтвердить в системном окне. При первом запуске установки Android может попросить разрешить установку из этого источника.

Для нового выпуска укажите одну версию в `desktop_win/update.py` и `android_app/pubspec.yaml` и увеличьте Android `versionCode` после знака `+`. Соберите Windows EXE и выполните `flutter build apk --release` в `android_app`. Опубликуйте один выпуск с тегом `vX.Y.Z` и приложите к нему `LocalTransfer-Setup-X.Y.Z.exe` и `LocalTransfer-Android-X.Y.Z.apk`. APK берётся из `android_app/build/app/outputs/flutter-apk/app-release.apk`.

Установленный и новый APK должны быть подписаны одним ключом. Текущая конфигурация использует отладочный ключ. Для последовательных тестовых выпусков используйте одну и ту же копию ключа.
